# 아침칠판 날씨 자동 입력 + 안전수칙 확장 — 설계

작성일: 2026-07-29

## 문제

**1. 날씨는 수동이다.** 아침칠판 `📅 날짜 및 날씨` 칸(`view-date`)에 `autoFillDashboard`가
`7월 29일 수요일`까지만 채운다(2317행). 날씨는 선생님이 매일 직접 친다.

**2. 안전수칙이 9일마다 반복된다.** `SAFETY_BY_MONTH`는 12개월 전부 정의돼 있고 계절도
반영돼 있으나, 각 월에 9개씩뿐이다. `getSafetyMsg`가 `pool[(날짜-1) % 9]`로 고르므로
(2307~2311행) **1일·10일·19일·28일이 같은 문구**다. 한 달에 세 번씩 반복돼 눈에 띈다.

사용자가 "2학기 계절 안전수칙이 없다"고 느낀 것은 실제로는 이 반복 때문이다. 8~2월 문구는
이미 존재하며 계절이 반영돼 있다.

## 조사 결과 (설계를 좌우한 사실)

| 확인 항목 | 결과 |
|---|---|
| Open-Meteo 날씨 API | ✅ API 키 불필요, `Access-Control-Allow-Origin: *` |
| Open-Meteo 지오코딩 API | ✅ CORS 통과, 한글 입력 가능 — **그러나 정확도가 낮다** |
| ipapi.co (IP 기반 위치) | ❌ Cloudflare 챌린지에 막혀 사용 불가 |

**지오코딩 정확도 실측:**

| 입력 | 결과 |
|---|---|
| `아산시` | ✅ 충청남도 아산시 (36.78361, 127.00417) |
| `아산` | ❌ 전라남도의 마을 |
| `천안` | ❌ **강원도** (충남 천안시가 아님) |
| `탕정`, `충청남도 아산` | ❌ 결과 없음 |

검색 결과를 자동으로 채택하면 `천안` 입력 시 1년 내내 강원도 날씨가 나온다.
**자동 채택은 하지 않는다.**

## 결정

### 1. 위치 — 설정에서 직접 고른다

브라우저 위치 권한(팝업)도, IP 추정도 쓰지 않는다. 설정에 지역 검색 UI를 두고,
**후보를 시·도와 함께 보여준 뒤 선생님이 명시적으로 고르게** 한다. 고른 좌표를 반 설정에
저장하고, 이후에는 저장된 좌표만 쓴다.

`천안` → `강원도`가 후보에 뜨면 선생님이 잘못됨을 알아채고 `천안시`로 다시 검색할 수 있다.
입력 도움말에 "시·군까지 붙여서 (예: 아산시)"를 명시한다.

검토했으나 채택하지 않은 대안:

- **브라우저 위치 권한** — 정확하지만 교실 태블릿에서 매번 팝업이 뜨거나 거부될 위험이 있다.
- **IP 기반 자동 감지** — 무료 서비스가 Cloudflare에 막혀 동작하지 않는다.
- **검색 1순위 자동 채택** — 위 실측대로 틀린 지역이 잡힌다.

### 2. 갱신 시점 — 아침에 한 번만

`autoFillDashboard`가 칠판을 새로 채울 때만 날씨를 받아온다. 그 뒤 선생님이 손으로 고친
내용은 **절대 덮어쓰지 않는다.** 오후에 날씨가 바뀌어도 반영하지 않는다.

`view-date`는 편집 가능한 칸이고 자동 저장이 걸려 있어, 주기적 갱신은 선생님이 적어둔
메모를 지울 수 있다.

### 3. 안전수칙 — 월별 31개

각 월 9개 → **31개**로 늘린다. `(날짜-1) % 31`이 되어 **한 달 안에서 한 번도 겹치지 않는다.**
`getSafetyMsg`는 이미 풀 길이를 나눗셈에 쓰므로 **로직은 고치지 않는다.**

기존 9개는 그대로 두고 22개씩 추가한다. 문구 결이 좋고 버릴 이유가 없다.
새로 쓰는 문구는 **안전 2/3, 인성·생활 1/3** 비율로 맞춘다.

## 데이터

반 설정 `rooms/$cid/settings/dashboardDefaults`에 3개 키를 추가한다.

| 키 | 타입 | 예 |
|---|---|---|
| `weatherLat` | number | `36.78361` |
| `weatherLon` | number | `127.00417` |
| `weatherPlace` | string | `아산시 (충청남도)` |

이 노드는 무인증 공개다. 저장되는 값은 **학교가 있는 시·군 단위 좌표와 지명**뿐이라
개인정보가 아니다. 학생 이름은 여기 들어가지 않는다(`rosterNames` 분리 설계 유지).

### 기본값

설정된 값이 없으면 **아산시(충청남도) `36.78361, 127.00417`** 를 쓴다. 이 좌표는 실측으로
검증했다. 현재 DB에 있는 학급 대부분(신리초·아산초·탕정초)이 아산시 소재라 맞는 값이고,
선생님은 설정을 만지지 않아도 날씨가 나온다.

다만 **파평초(파주)처럼 다른 지역 학교에는 틀린 날씨가 나간다.** 그래서 기본값을 쓰는 중일
때는 설정 화면에 `현재 설정: 아산시 (충청남도) — 기본값`처럼 **기본값임을 명시**해,
다른 지역 선생님이 알아채고 바꿀 수 있게 한다. 한 번 고르면 그 반의 저장값이 우선한다.

## 화면

### 설정 모달 — 지역 선택

`학급명 / 총 학생 수` 줄(1165~1168행) 바로 아래, 학생 명단 그리드(1170행) 위에 넣는다.

```
📍 학교 지역   [ 아산시            ] [찾기]
   현재 설정: 아산시 (충청남도)

   (찾기 누르면 후보가 아래에 뜸)
   ○ 아산시  · 충청남도
   ○ 아산시장 · 전라북도
```

- 후보는 최대 5개, `이름 · 시·도` 형식으로 표시한다. 시·도를 반드시 함께 보여준다.
- 후보를 클릭하면 좌표와 표시명이 입력 상태에 반영되고, **설정 저장 시** 함께 저장된다.
- 결과가 없으면 "결과가 없어요. 시·군까지 붙여보세요 (예: 아산시)"를 보여준다.

### 아침칠판 — 날짜 및 날씨

```
7월 30일 목요일  ☀️ 맑음 28℃
```

날짜 문자열 뒤에 공백 2칸 + `이모지 한글날씨 기온℃`를 붙인다.

## 실패 처리 — 칠판은 절대 막지 않는다

날씨는 부가 기능이다. 아래 경우 모두 **날짜만 넣고 조용히 넘어간다** (현재와 동일 동작).

- 지역이 설정되지 않음 (`weatherLat`/`weatherLon` 없음)
- 인터넷 끊김, API 오류, 타임아웃
- 알 수 없는 `weather_code`

날씨 요청에 **타임아웃 5초**를 건다. 응답이 늦어도 칠판 자동 채우기가 지연되지 않도록,
날짜·시간표·당번 등 나머지 채우기를 막지 않는다.

## 수정 지점

| # | 위치 | 내용 |
|---|---|---|
| 1 | `index.html` 1168행 뒤 | 설정 모달에 지역 검색 UI 추가 |
| 2 | `openSettingsModal` (4233행 부근) | 저장된 `weatherPlace` 표시 |
| 3 | `saveSettingsData` (4291행 부근) | `weatherLat/Lon/Place` 저장 |
| 4 | 신규 함수 | `weatherSearchPlace()` — 지오코딩 호출 + 후보 렌더 |
| 5 | 신규 함수 | `weatherCodeText(code)` — WMO 코드 → 이모지+한글 |
| 6 | 신규 함수 | `fetchWeatherText(lat, lon)` — 현재 날씨 → `"☀️ 맑음 28℃"` |
| 7 | `autoFillDashboard` (2317행) | 날짜 뒤에 날씨 붙이기 |
| 8 | `SAFETY_BY_MONTH` (2171행) | 12개월 × 9개 → 31개 |

`getSafetyMsg`는 수정하지 않는다.

두 기능은 서로 의존하지 않는다. 8번(안전수칙)은 순수 데이터 변경이라 네트워크·실패처리가
없고 위험이 사실상 없으므로 **먼저 구현해 따로 배포해도 된다.** 1~7번(날씨)은 외부 API와
새 UI가 얽혀 있으니 뒤에 둔다.

## 비목표 (이번에 하지 않음)

- 오후 날씨 자동 갱신 / 주기적 폴링
- 미세먼지·자외선 지수
- 브라우저 위치 권한 사용
- 주간 예보
- 안전수칙을 반별로 편집하는 기능 (코드 상수 유지)
- `getSafetyMsg` 선택 알고리즘 변경

## 검증

1. `weatherCodeText`가 위 표의 모든 코드에 대해 정확한 문자열을 내는지 (단위 테스트)
2. 알 수 없는 코드(예: 4, 100)에 빈 문자열을 내는지 (단위 테스트)
3. 지역 미설정 상태에서 `autoFillDashboard`가 **지금과 똑같이** 날짜만 넣는지
4. 지역 설정 후 칠판 자동 채우기에 `☀️ 맑음 28℃` 형태가 붙는지
5. 네트워크를 끊고 자동 채우기를 실행해도 칠판이 정상적으로 채워지는지
6. 각 월 안전수칙이 31개인지, 1일과 10일·19일·28일 문구가 서로 다른지 (단위 테스트)
7. 저장 후 공개 노드에 좌표·지명만 있고 학생 이름이 없는지 (무인증 curl)
