## Antigravity에게 붙여넣을 지시 (이것만 복사)
```
첨부한 "직업x옷_그림_목록_Antigravity프롬프트.md" 의 표 중 [이번에 만들 직업 이름] 부분을 위에서부터 전부 만들어줘.
1. 각 줄 프롬프트를 그대로 쓰고, 파일은 표의 "저장 경로" 그대로 PNG로 저장해.
2. 모든 그림은 배경을 지운 투명 PNG, 크기 600x800(세로 3:4), 정면 전신, 같은 자세.
3. 기준 그림(예: assets/avatars/mage_f.png)과 얼굴·머리색·머리 모양·체형이 똑같은 아이로. 바뀌는 건 옷뿐이야.
4. 손에는 아무것도 들지 마(무기·방패·지팡이·악기 없음). 무기는 앱이 따로 그려.
5. 같은 그림을 두 벌 만들지 마. 다시 그리면 덮어써서 한 파일만 남겨.
6. index.html, list.json, 버전기록.md 는 절대 고치지 말고 git commit/push 도 하지 마. (등록·배포는 클로드가 해)
7. 다 끝나면 만든 파일 개수와 이름 목록을 알려줘.
```
